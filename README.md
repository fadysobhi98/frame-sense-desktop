# Frame Sense – Project Starter Kit

A real starter repository for the approved Frame Sense product scope.

- Desktop foundation: Tauri 2 + Rust + React + TypeScript.
- Mobile foundation: Flutter scaffold.
- Product requirements: `docs/FRAME_SENSE_MASTER_SPECIFICATION_AR_V1.1.docx` and `.md`.
- UI references: `docs/UI_REFERENCES/`.

This is **not the completed Frame Sense product**. The first foundation includes project-folder creation and safe byte-copy import scaffolding. RAW development, AI models, color pipeline, queue execution, remote sync, authentication, and production export remain planned until implemented and tested.

See `README_AR.md` for Windows setup and run instructions.
